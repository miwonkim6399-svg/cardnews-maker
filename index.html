자동 게시 (Instagram API 연동)

비즈니스·크리에이터 계정을 연결해 두면 버튼 한 번으로 캐러셀 + 캡션이 바로 게시됩니다. 설정에서 액세스 토큰을 넣어 주세요.

    연동 설정

    입력한 키는 이 브라우저(localStorage)에만 저장되며 Anthropic · Meta · imgbb 서버로만 직접 전송됩니다. 공용 PC에서는 사용 후 꼭 지워 주세요.

    AI 작성 (Claude)

    console.anthropic.com → API Keys 에서 발급. 비워 두면 기본 템플릿으로 생성돼요.

    Instagram 자동 게시

    Instagram API는 공개 URL의 JPEG만 받기 때문에, 카드 이미지를 imgbb에 올린 뒤 그 주소로 게시합니다. 자세한 발급 방법은 README.md를 참고하세요.
