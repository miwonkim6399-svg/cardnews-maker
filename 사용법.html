2카드뉴스 만들기

  1. 관심사를 고르세요. 일상 정보 · 부동산 · 프랑스 자수 · 여행 · 독서 · 식물 키우기 · 산책 중에서 고르면, 어울리는 디자인과 색이 자동으로 골라져요.
  2. 추천 주제를 누르거나 주제 칸에 직접 쓰세요. (예: 몬스테라 잘 키우는 법)
  3. 말투와 카드 수(5 · 7 · 9장)를 고르세요.
  4. 작성 방식
    • 기본 문구: 키 없이 바로 만들어져요. 관심사에 맞춘 문구가 들어가요.
    • AI 작성: 주제에 딱 맞는 실제 내용을 써 줘요. 오른쪽 위 ⚙ 설정에 Anthropic API 키를 넣어야 해요 (사용한 만큼 요금이 나가요).
  5. 카드뉴스 만들기를 누르면 카드와 인스타그램 캡션이 함께 완성돼요.

나의 브랜드 (한 번 설정하면 계속 유지)

  • 프로필 사진: 동그란 ＋를 눌러 얼굴 사진이나 로고를 넣으면 모든 카드 아래 계정명 옆에 표시돼요.
  • 인스타그램 계정명: @buccaneerscholar가 기본으로 들어가 있어요.
  • 대표 색: 포레스트 · 세이지 · 앤틱 골드 · 테라코타 · 더스티 로즈 · 버건디 · 네이비 · 딥 틸 · 라벤더 등. 무지개 동그라미로 직접 고를 수도 있어요.
  • 제목 글꼴: 명조 · 고운바탕 · 나눔명조 · 고딕 · 고운돋움 · 손글씨
  • 정렬: 기본(디자인에 맞게) · 왼쪽 · 가운데
  • 크기 비율: 인스타 피드는 4:5를 추천해요. 스토리는 9:16.

4카드 고치기 · 사진 넣기

  • 미리보기 아래 작은 카드를 누르거나 ‹ ›로 넘기면서, 오른쪽 카드 편집에서 라벨 · 제목 · 본문을 고쳐요.
  • 제목에서 강조하고 싶은 단어를 *별표*로 감싸면 대표 색으로 바뀌어요. 예: 물주기 *기준*
  • 배경 사진: 🖼 사진 넣기로 여행 · 식물 · 자수 사진을 넣으면 사진 위에 흰 글씨로 바뀌어요. 사진 어둡게 막대로 글씨를 또렷하게 조절하고, 표지에도 쓰기로 같은 사진을 표지에 넣을 수 있어요.
  • 카드 정리: ‹ › 순서 바꾸기 · ⧉ 복제 · ＋ 추가 · 🗑 삭제 (최대 10장)
  • 이 카드만 다른 색: 예를 들어 마지막 장만 파란색으로 만들 수 있어요.
  • 인스타 미리보기: 실제 인스타그램 게시물과 프로필 그리드에서 어떻게 보일지 확인해요.

5폴더에 저장하기

  1. 오른쪽 저장 · 올리기에서 📁 내 폴더에 저장을 누르세요.
  2. 처음 한 번은 저장할 폴더를 고르는 창이 떠요. 블로그, 카드뉴스,홈페이지 자동화 → 인스타그램_업로드 폴더를 고르고 폴더 선택 → 파일 수정 허용을 누르세요.
  3. 다음부터는 버튼만 누르면 그 폴더 안에 2026-11-23_주제 같은 새 폴더가 생기고, 카드 PNG와 캡션.txt가 저장돼요.
💡 폴더 바로 저장은 PC의 크롬 · 엣지에서 돼요. 휴대폰이나 다른 브라우저에서는 전체 카드 ZIP으로 받기로 받아 압축을 풀면 돼요.

6인스타그램에 올리기

폴더에 저장된 이미지는 바로 인스타그램에 올릴 수 있어요. GitHub 사이트는 휴대폰에서도 쓸 수 있게 해 주는 주소이고, 이미지 파일은 폴더에 있으니 그대로 쓰면 돼요.

PC에서 (폴더 이미지로)

  1. instagram.com 에 @buccaneerscholar로 로그인돼 있는지 확인하세요. (왼쪽 아래 프로필 사진)
  2. 왼쪽 만들기(＋) → 컴퓨터에서 선택 → 저장된 폴더에서 카드 이미지를 Ctrl+A로 한꺼번에 선택하세요. 파일 이름 순서가 카드 순서예요.
  3. 자르기 화면에서 비율을 원본(또는 4:5)으로 맞추고 다음을 누르세요.
  4. ⭐ 문구 입력 칸에 캡션을 붙여넣으세요. 사이트의 캡션 복사를 누르거나, 폴더의 캡션.txt를 열어 내용을 Ctrl+A → Ctrl+C로 복사한 뒤 문구 칸에 Ctrl+V 하세요.
  5. 공유하기를 누르면 끝!
⚠ 파일 캡션.txt 자체를 복사하면 파일 이름만 들어가요. 꼭 파일을 열어서 안의 글을 복사하세요.

휴대폰에서 (가장 간단)

  1. 휴대폰 인스타그램 앱이 @buccaneerscholar 계정인지 확인하세요.
  2. 휴대폰으로 사이트를 열고 카드를 만든 뒤 내 인스타그램에 올리기를 누르세요.
  3. Instagram으로 공유 → 공유창에서 Instagram → 피드를 고르세요. 캡션은 자동 복사돼 있어요.
  4. 문구 칸을 길게 눌러 붙여넣기 → 공유!

이미 올렸는데 캡션을 빠뜨렸다면

게시물을 열고 오른쪽 위 ⋯ → 수정 → 문구 칸에 붙여넣기 → 완료. 다시 올릴 필요 없어요.

7내 보관함 · 되돌리기

  • 📚 이 작품을 보관함에 저장: 만든 카드뉴스를 보관해 두고, 상단 📚 내 보관함에서 다시 열거나 복사해서 비슷한 새 작품을 만들 수 있어요.
  • ↶ 되돌리기 · ↷ 다시하기 (키보드 Ctrl+Z / Ctrl+Y). 실수로 카드를 지워도 되살릴 수 있어요.
  • ✚ 새로 만들기: 지금 작업을 비우고 새로 시작해요. 브랜드 설정(계정명 · 프로필 · 색 · 글꼴)은 그대로예요. 남기고 싶은 작업은 먼저 보관함에 저장하세요.

8관심사별 추천 조합

관심사디자인 · 색추천 주제 예시팁
부동산프라퍼티 · 네이비청약 가점 높이는 방법, 전세 계약 전 체크리스트숫자는 출처(국토부 실거래가 등)를 캡션에 함께 적으면 신뢰가 올라가요.
프랑스 자수린넨 · 테라코타입문 준비물, 기본 스티치완성작 사진을 표지에 넣고 포토 디자인도 써 보세요.
여행트래블 저널 · 딥 틸파리 3박 4일 산책 여행, 제주 동쪽 코스9장으로 하루 코스를 시간 순서로 정리하면 저장이 많이 돼요.
독서북 노트 · 버건디이번 달 읽은 책, 인생 문장 다섯 줄「마음에 남은 문장」 카드에 실제 밑줄 문장을 적어 주세요.
식물 키우기가든 · 세이지몬스테라 잘 키우는 법, 겨울철 관리우리 집 식물 사진을 배경으로 넣으면 훨씬 생생해요.
산책가든 · 앤틱 골드서울숲 가을 산책 코스, 아침 30분 걷기계절 사진 + 짧은 감성 문장이 잘 어울려요. 말투는 「감성적인」을 추천해요.
💡 인스타그램은 꾸준함이 가장 중요해요. 관심사 6가지를 요일별로 정해 두면 소재 걱정이 줄어요. 예: 월 부동산 · 수 자수 · 금 독서 · 주말 여행/산책/식물

miwonkim6399 게시물 삭제

  1. miwonkim6399로 로그인 → 프로필 → 지울 게시물을 여세요.

  3. 삭제한 게시물은 설정 → 내 활동 → 최근 삭제됨에 30일 동안 보관되고 그 뒤 완전히 사라져요.

miwonkim6399 계정 삭제

  1. 휴대폰 인스타그램 앱에서 miwonkim6399로 전환 → 프로필 → 오른쪽 위 ≡ → 계정 센터.
  2. 개인정보 → 계정 소유권 및 관리 → 비활성화 또는 삭제 → miwonkim6399 선택.
  3. 계정 삭제를 고르고 → 이유 선택 → 비밀번호 입력 → 계정 삭제.

10자주 묻는 질문

사이트가 대신 인스타그램에 올려 주나요?

인스타그램은 로그인한 본인만 올릴 수 있어서, 사이트는 이미지와 캡션을 준비해 주고 마지막 공유 버튼은 직접 누르는 방식이에요. 비즈니스 계정이라면 「자동 게시(고급)」 설정으로 버튼 한 번에 올리는 것도 가능해요 (README.md 참고).

휴대폰에서 만든 작업이 컴퓨터에서 안 보여요.

작업은 각 브라우저에 따로 저장돼요. 한 기기에서 끝까지 만들거나, 완성 이미지를 폴더/ZIP으로 저장해 두세요.

글자가 카드에서 넘쳐요.

글이 길면 글자 크기가 자동으로 줄어들어요. 그래도 답답하면 본문을 2~3줄로 줄이거나 카드를 하나 더 추가해 나눠 주세요.

사진을 넣었더니 글씨가 잘 안 보여요.

사진 어둡게 막대를 오른쪽으로 옮기세요 (40~55% 추천).

사이트를 고치고 싶어요.

Claude에게 "카드뉴스메이커 ○○ 바꿔줘"라고 말하면 고쳐서 GitHub에 다시 올려 줘요. 1~2분 뒤 같은 주소에 반영돼요.
